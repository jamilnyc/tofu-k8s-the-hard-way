# Kubernetes The Hard Way — EC2 Infrastructure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provision the 4 Debian 12 EC2 instances (jumpbox, server, node-0, node-1) required by the Kubernetes The Hard Way prerequisites, as OpenTofu code, on a single shared VPC.

**Architecture:** A flat set of `.tf` files at the repo root (no modules — small, single-environment project). Networking, security group, SSH keypair, and instances are separate files by responsibility. State lives remotely in S3 with DynamoDB locking. Root SSH access is enabled via cloud-init to match the KTHW guide's assumptions.

**Tech Stack:** OpenTofu (>= 1.7), AWS provider (~> 5.0), TLS provider (~> 4.0), Local provider (~> 2.5), HTTP provider (~> 3.4).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-28-ec2-infra-design.md` — this plan implements it in full; consult it for rationale.
- **NEVER run `tofu apply` or `tofu destroy`** — not in any step of this plan, and not unless the user explicitly asks for it later. `tofu init`, `tofu validate`, `tofu fmt`, and `tofu plan` are all read-only/local with respect to AWS resources (they don't create, modify, or delete anything) and are safe to run freely.
- AWS profile: `CHANGEME-aws-profile`. Region: `us-east-1`.
- State backend: S3 bucket `CHANGEME-terraform-state-bucket`, key `k8s-hard-way.tfstate`, DynamoDB table `terraform-state-lock` (all pre-existing, `CHANGEME-aws-profile` has `AdministratorAccess`).
- Machines/IPs: jumpbox `10.0.1.10` (10GB disk), server `10.0.1.11` (20GB), node-0 `10.0.1.12` (20GB), node-1 `10.0.1.13` (20GB). All `t3.medium`.
- VPC `10.0.0.0/16`, public subnet `10.0.1.0/24` in `us-east-1a`.
- AMI: latest Debian 12 (bookworm) AMD64, owner `136693071363`, resolved via data source — never hardcode an AMI ID.
- SSH: SG allows port 22 only from the operator's current public `/32`, plus all traffic self-referenced within the SG. Keypair is generated by Tofu (`ed25519`), private key written to `./ssh/id_ed25519` (0600), root login enabled via cloud-init.
- File layout (fixed, do not deviate): `backend.tf`, `versions.tf`, `main.tf`, `keypair.tf`, `instances.tf`, `variables.tf`, `outputs.tf`, `cloud-init.yaml`, `.gitignore`, `README.md`.

### Task 2: Networking — provider, VPC, subnet, internet gateway, route table

**Files:**
- Create: `main.tf`

**Interfaces:**
- Consumes: `var.aws_region`, `var.aws_profile`, `var.vpc_cidr`, `var.subnet_cidr`, `var.availability_zone` (from Task 1).
- Produces: `aws_vpc.main`, `aws_subnet.public` — later tasks (`keypair.tf` unaffected, `instances.tf`) reference `aws_subnet.public.id`.

- [ ] **Step 1: Write `main.tf`**

```hcl
provider "aws" {
  region  = var.aws_region
  profile = var.aws_profile
}

resource "aws_vpc" "main" {
  cidr_block           = var.vpc_cidr
  enable_dns_support   = true
  enable_dns_hostnames = true

  tags = {
    Name = "k8s-hard-way"
  }
}

resource "aws_subnet" "public" {
  vpc_id                  = aws_vpc.main.id
  cidr_block              = var.subnet_cidr
  availability_zone       = var.availability_zone
  map_public_ip_on_launch = true

  tags = {
    Name = "k8s-hard-way-public"
  }
}

resource "aws_internet_gateway" "main" {
  vpc_id = aws_vpc.main.id

  tags = {
    Name = "k8s-hard-way"
  }
}

resource "aws_route_table" "public" {
  vpc_id = aws_vpc.main.id

  route {
    cidr_block = "0.0.0.0/0"
    gateway_id = aws_internet_gateway.main.id
  }

  tags = {
    Name = "k8s-hard-way-public"
  }
}

resource "aws_route_table_association" "public" {
  subnet_id      = aws_subnet.public.id
  route_table_id = aws_route_table.public.id
}
```

### Task 3: Security group — SSH from operator IP + intra-cluster traffic

**Files:**
- Modify: `main.tf` (append to the file created in Task 2)

**Interfaces:**
- Consumes: `aws_vpc.main.id` (Task 2).
- Produces: `aws_security_group.cluster`, `data.http.my_ip` — `instances.tf` references `aws_security_group.cluster.id`.

- [ ] **Step 1: Append the security group and IP-detection data source to `main.tf`**

```hcl
data "http" "my_ip" {
  url = "https://checkip.amazonaws.com"
}

locals {
  my_ip_cidr = "${chomp(data.http.my_ip.response_body)}/32"
}

resource "aws_security_group" "cluster" {
  name        = "k8s-hard-way"
  description = "KTHW cluster: SSH from operator IP, all traffic within the group"
  vpc_id      = aws_vpc.main.id

  ingress {
    description = "SSH from operator's current public IP"
    from_port   = 22
    to_port     = 22
    protocol    = "tcp"
    cidr_blocks = [local.my_ip_cidr]
  }

  ingress {
    description = "All traffic between cluster members"
    from_port   = 0
    to_port     = 0
    protocol    = "-1"
    self        = true
  }

  egress {
    from_port   = 0
    to_port     = 0
    protocol    = "-1"
    cidr_blocks = ["0.0.0.0/0"]
  }

  tags = {
    Name = "k8s-hard-way"
  }
}
```

### Task 5: Cloud-init (root SSH enablement) + the 4 EC2 instances

**Files:**
- Create: `cloud-init.yaml`
- Create: `instances.tf`

**Interfaces:**
- Consumes: `aws_subnet.public.id` (Task 2), `aws_security_group.cluster.id` (Task 3), `aws_key_pair.ssh.key_name` and `tls_private_key.ssh.public_key_openssh` (Task 4), `var.machines`, `var.instance_type`, `var.root_volume_sizes` (Task 1).
- Produces: `aws_instance.machine` (a `for_each` map keyed by machine name, each with `.public_ip`, `.private_ip`) — `outputs.tf` consumes this.

- [ ] **Step 1: Write `cloud-init.yaml`**

```yaml
#cloud-config
ssh_pwauth: false
runcmd:
  - mkdir -p /root/.ssh
  - chmod 700 /root/.ssh
  - echo "${ssh_public_key}" >> /root/.ssh/authorized_keys
  - chmod 600 /root/.ssh/authorized_keys
  - sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin yes/' /etc/ssh/sshd_config
  - systemctl restart ssh
```

- [ ] **Step 2: Write `instances.tf`**

```hcl
data "aws_ami" "debian_12" {
  most_recent = true
  owners      = ["136693071363"]

  filter {
    name   = "name"
    values = ["debian-12-amd64-*"]
  }

  filter {
    name   = "virtualization-type"
    values = ["hvm"]
  }

  filter {
    name   = "root-device-type"
    values = ["ebs"]
  }
}

resource "aws_instance" "machine" {
  for_each = var.machines

  ami                    = data.aws_ami.debian_12.id
  instance_type          = var.instance_type
  subnet_id              = aws_subnet.public.id
  private_ip             = each.value
  vpc_security_group_ids = [aws_security_group.cluster.id]
  key_name               = aws_key_pair.ssh.key_name

  associate_public_ip_address = true

  root_block_device {
    volume_size = var.root_volume_sizes[each.key]
    volume_type = "gp3"
  }

  user_data = templatefile("${path.module}/cloud-init.yaml", {
    ssh_public_key = tls_private_key.ssh.public_key_openssh
  })

  tags = {
    Name = each.key
  }
}
```
